# 개인 웹사이트 설계

작성일: 2026-10-21

## 목적과 합의한 범위

이 사이트는 Jihong Min의 연구, 영화, 글을 동등한 세 축으로 소개한다. 방문자는 한 장의 양면 소개 카드에서 사람과 활동을 파악한 뒤 관심 있는 분야의 독립 페이지로 이동한다. 제공된 `portfolio-plan-v2.png`는 화면 구조와 분위기를 설명하는 참고 이미지이며, 이미지 속 예시 제목과 문구를 검증된 게시 콘텐츠로 간주하지 않는다.

첫 버전은 한국어와 영어를 지원하는 Astro 정적 사이트로 만들고, 이 저장소의 GitHub Pages에 게시한다. 읽기 기록과 사이트 안에서 기록을 추가하는 소유자 화면은 후속 범위다. 초기 버전에서 영화 감상 목록은 사용자가 제공하는 CSV 파일로 갱신하고, 글 페이지는 프로페셔널 Instagram 계정의 모든 게시물을 공식 API로 매일 동기화한다.

## 화면과 이동

| 경로 | 주요 내용 | 콘텐츠 출처 |
| --- | --- | --- |
| `/ko/`, `/en/` | 양면 소개 카드 | 직접 작성한 한국어·영어 문구 |
| `/ko/research/`, `/en/research/` | 프로젝트, 설명, 개요·코드 링크 | 저장소의 콘텐츠 파일 |
| `/ko/cinema/`, `/en/cinema/` | 직접 만든 영화와 감상 목록 | 작품 파일, CSV에서 변환한 데이터 |
| `/ko/writing/`, `/en/writing/` | Instagram 게시물 목록 | 마지막으로 성공한 API 동기화 결과 |

루트 `/`는 한국어 카드로 이동한다. 상단 `한국어 / English` 전환은 현재 분야에 대응하는 다른 언어 경로로 이동한다. 각 분야 페이지에는 동일 언어의 카드로 돌아가는 링크가 있다. 직접 작성한 소개, 연구 설명, 영화 소개와 탐색 문구는 두 언어로 제공한다. Instagram 본문과 CSV에서 온 영화 제목·한줄평은 원문을 유지한다.

카드 앞면에는 이름, 소속과 분야, 연락처 및 외부 프로필 링크를 둔다. 뒷면에는 짧은 소개와 연구·영화·글로 이어지는 문장 속 링크, CV 링크를 둔다. 사용자는 카드 자체를 클릭하거나 탭해 뒤집을 수 있고, 별도 조작 버튼을 키보드로 사용할 수 있다. 카드 안의 링크 조작은 카드 전환을 일으키지 않는다. 모바일에서는 내용이 잘리거나 겹치지 않도록 카드의 크기와 문장 배치를 조정한다. 시안의 넓은 여백, 얇은 경계선, 간결한 타이포그래피를 시각적 기준으로 삼는다.

연구 페이지는 시안의 프로젝트 구성을 출발점으로 삼되, 실제 프로젝트 설명과 링크가 준비된 항목만 게시한다. 저장소에 있는 CV PDF를 소개 카드에서 연결한다. 기존 `paper_study/` PDF는 별도 검토 없이 자동으로 연구 목록에 노출하지 않는다. 영화 페이지의 직접 만든 작품은 제목, 짧은 설명, 영상 링크를 수동으로 관리한다. 영상은 방문자가 선택할 때 재생한다. 글 페이지는 별도 선별 규칙 없이 Instagram 계정의 모든 피드 게시물과 릴스를 최신 순으로 보여주며, 목록은 정적 페이지로 나누고 각 항목에서 원문으로 이동할 수 있다.

## 콘텐츠 구조와 갱신

Astro의 공통 레이아웃은 카드, 분야 페이지, 언어 전환을 공유한다. 직접 작성하는 연구·작품 콘텐츠와 번역 문구는 저장소 파일로 관리한다. 영화 감상 목록과 Instagram 게시물은 각각 별도의 정규화된 데이터 파일을 읽는다. 방문자 브라우저에서 외부 서비스 인증을 수행하지 않는다.

### 영화 감상 목록

사용자가 CSV를 제공하면 로컬 가져오기 명령이 필수 열과 값 형식을 검증한다. 입력 파일은 화면에 필요한 `ID`, `URL`, `Title`, `Type`, `Year`, `WatchedAt`, `Rating`, `Review`, `Spoiler` 열을 인식한다. `Type`이 `MOVIE`인 항목만 선택하고 ID 중복을 제거한 뒤, 제목·제작연도·별점(5점 기준)·한줄평·원문 링크·정렬용 감상일·스포일러 여부만 정적 데이터 파일로 내보낸다. 원본 CSV는 공개 저장소에 커밋하지 않는다. 변환 결과를 커밋하면 사이트가 다시 빌드된다.

감상 목록은 감상일 최신 순으로 보여주고, 날짜가 없는 항목은 안정적인 보조 순서로 배치한다. 한줄평이 없는 항목은 평점과 기본 정보만 보여준다. `Spoiler`로 표시된 한줄평은 기본 화면에서 숨기고 방문자가 직접 펼칠 수 있게 한다. CSV의 열이 빠졌거나 값이 잘못되면 가져오기는 실패하며 기존 데이터 파일을 덮어쓰지 않는다. 게시할 항목이 없으면 예시 평점 대신 안내 문구와 Watcha Pedia 프로필 링크를 보여준다.

사이트와 배포 작업은 Watcha Pedia에서 데이터를 직접 수집하지 않는다. 공개된 타사 추출 도구는 CSV를 생성하지만 내부 API를 호출하며, Watcha Pedia는 데이터 수집을 금지한다고 안내한다. 따라서 추출 도구 실행은 사이트 갱신 자동화에 포함하지 않는다. 사용자가 제공한 CSV 이후의 검사·변환·게시 흐름만 이 설계의 범위다.

### Instagram 게시물

구현 초기에 실제 프로페셔널 계정으로 공식 API의 게시물 조회와 필요한 권한을 검증한다. 이후 GitHub Actions 예약 작업이 하루 한 번 게시물의 ID, 캡션, 유형, 게시 시각, 원문 링크와 표시 가능한 미리보기 정보를 가져온다. 인증 값은 GitHub Actions 비밀값에 보관한다. 작업은 결과를 검증해 마지막 성공 데이터를 갱신하고 사이트를 빌드·배포한다. 성공한 데이터는 저장소에 스냅샷으로 남겨 일반 콘텐츠 수정 때 API 가용성과 무관하게 빌드할 수 있게 한다.

API 요청, 인증 또는 데이터 검증이 실패하면 마지막으로 성공한 목록과 기존 공개 사이트를 유지하고 작업 실패를 기록한다. 최초 연결 전에는 빈 게시물 카드를 만들지 않고 Instagram 프로필로 연결하는 안내를 보여준다. 예약 작업은 GitHub 정책에 따라 장기간 저장소 활동이 없으면 비활성화될 수 있으므로, 운영 문서에 실행 상태 점검, 인증 갱신, 작업 재활성화 절차를 둔다. 자동 갱신은 예약 작업과 API 인증이 정상인 동안 하루 단위로 이루어진다.

## 접근성, 오류와 검증

카드 전환과 스포일러 펼치기는 키보드 및 보조 기술로 사용할 수 있는 명시적 조작 요소를 갖는다. 움직임 줄이기 설정에서는 카드 회전 효과를 줄인다. 내부 링크는 명확한 텍스트를 사용하고 외부 링크는 원문 대상이 구분되게 한다. 한국어·영어 경로에는 각각 맞는 문서 언어와 페이지 제목을 지정한다.

완료 기준은 다음과 같다.

1. 한국어와 영어의 카드 및 세 분야 페이지가 모두 생성되고, 카드 뒤집기·링크·언어 전환·돌아가기 흐름이 마우스, 터치, 키보드에서 작동한다.
2. 모바일 너비에서 카드와 세 페이지를 내용 손실 없이 읽을 수 있다.
3. CSV 가져오기가 정상 파일을 정규화하고, 누락 열·잘못된 별점·중복 ID·스포일러·한줄평 없는 항목을 의도대로 처리한다. 실패 시 기존 데이터가 보존된다.
4. Instagram API의 실제 계정 조회가 확인되고, 성공 시 새 게시물이 반영되며 실패 시 마지막 성공 목록이 유지된다. 인증 값이 빌드 결과에 포함되지 않는다.
5. 정적 빌드와 GitHub Pages 배포가 성공하고 CV 및 외부 프로필 링크가 동작한다. 공개 화면에는 검증되지 않은 예시 영화나 평점이 없다.

초기 게시에 필요한 사용자 자료는 공개할 연락처와 프로필 URL, 양 언어의 소개 및 연구 문구, 직접 만든 영화의 영상 링크, 첫 영화 CSV, Instagram 계정의 API 연결이다. 실제 값이 제공되기 전에는 해당 항목을 숨기거나 안내 상태로 표시하며 임의의 콘텐츠를 게시하지 않는다. 저장소에 이미 있는 CV PDF는 링크 대상으로 사용할 수 있다.

## 후속 범위

읽기 기록과 `+ Add` 소유자 화면은 첫 버전에 포함하지 않는다. 후속 단계에서 저장·인증 방식을 별도로 설계한다. 영화 감상 기록의 Watcha Pedia 직접 자동 동기화도 현재 범위에 포함하지 않는다.
